# Microservicio de Inventario - Arquitectura SOA Desacoplada

Proyecto desarrollado para la entrega final del caso de estudio, implementando un servicio REST que transforma un monolito distribuido en una arquitectura orientada a servicios (SOA) con bases de datos aisladas (*Database-per-Service*) y resiliencia ante fallos.

## Estructura del Repositorio
- `src/server.js`: Código fuente principal del microservicio de inventario y sus contratos REST.


## Requisitos Previos
Debes tener instalado en tu equipo:
- [Node.js](https://nodejs.org/) (Versión 16 o superior recomendada).
